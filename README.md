# PreDash Classroom · 수강생 투자 대시보드

선생님의 PreDash와 분리한 수업용 코드입니다. 개인 계좌를 조회하고 시장·기업·수급·차트를 보면서 나만의 투자 화면을 실습합니다. 실제 주문 전송 기능은 없습니다.

## 수강생 시작 순서

1. **Fork**: 이 저장소의 **Fork** 버튼을 눌러 본인 GitHub 계정에 복사합니다.
2. **앱 배포**: Streamlit Community Cloud에서 본인 Fork 저장소를 선택하고, 브랜치는 `main`, 실행 파일은 `app.py`로 배포합니다.
3. **로그인 비밀번호 설정**: 배포한 본인 앱의 **Settings → Secrets**에 아래 형식으로 긴 개인 비밀번호를 설정하고 **Save** 합니다. Secrets에 필수로 설정할 항목은 `APP_PASSWORD`입니다. 아래 값은 예시이므로 본인 비밀번호로 바꾸세요. 저장소 파일에는 입력하지 않습니다.

   ```toml
   APP_PASSWORD = "본인만 아는 긴 비밀번호로 변경"
   ```

4. **로그인**: 배포한 앱을 열고 **대시보드 비밀번호**에 위 비밀번호를 입력한 뒤 **내 대시보드 열기**를 누릅니다.
5. **공공 API 연결**: 사이드바의 **08 데이터 연결**(연결 설정) → **01 · 공공 데이터 API**에서 필요한 키만 입력하고 **입력한 API 키 적용**을 누릅니다. 수업 중에는 현재 세션에서 바로 사용할 수 있습니다. 공공데이터 → DART 순서로 시작하고, KRX·관세청은 필요한 기능을 실습할 때 추가하세요. 네 가지 키를 모두 준비할 필요는 없습니다. 장기 사용을 원하면 아래의 공공 API Secrets 설정을 선택할 수 있습니다.
6. **한국투자증권 모의투자 계좌 연결**: 같은 화면의 **02 · 한국투자증권 계좌 → 내 증권사 계좌 연결**에서 **투자 환경 → 모의투자**를 선택합니다. [한국투자증권 API 신청](https://apiportal.koreainvestment.com/)으로 준비한 본인 **모의투자용 App Key·App Secret**, **계좌번호 앞 8자리·뒤 2자리**를 입력하고 **연결 확인**을 누릅니다. 모의투자용 키와 계좌를 사용하세요. 잔고 조회가 성공하면 계좌 연결 상태가 표시되며, **KIS 연결 진단 · 잔고 조회 권한 확인**으로 토큰 발급·잔고 조회를 확인할 수 있습니다.
7. **실습 시작**: 관심종목·투자 근거·대시보드를 자신의 기획에 맞춰 수정합니다. 실제 주문 전송 기능은 없습니다.

## 공공 API 키 사용과 저장

| 화면 항목 | 사용 기능 | Secrets 항목명 |
| --- | --- | --- |
| 공공데이터 | 종목 · 일별 시세, 관심종목·모의투자 시세 | `DATA_GO_KR_SERVICE_KEY` |
| DART | 기업 실적 · 공시, 재무·공시 분석 | `DART_CRTFC_KEY` |
| KRX | 거래량 · 거래대금 · 시가총액 | `KRX_AUTH_KEY` |
| 관세청 | 품목별 국가별 수출입, 수출 흐름 분석 | `CUSTOMS_API_KEY` |

각 항목의 **발급/신청** 버튼에서 키 발급과 필요한 API 활용 승인을 준비합니다. 화면의 **연결됨** 표시는 키가 설정되어 있다는 뜻이며, 실제 조회 성공이나 활용 승인 여부를 보장하지 않습니다. 사용할 기능에서 조회 결과도 확인하세요.

- **수업 중 세션 입력**: 연결 설정 화면에 키를 입력하고 적용합니다. 같은 항목에 세션 키와 Secrets 키가 있으면 세션 키를 우선 사용합니다. 입력란을 비워서 적용하면 기존 키를 유지합니다.
- **선택 사항 · 장기 사용**: 본인 Fork로 배포한 앱의 **Settings → Secrets**에 필요한 공공 API 항목만 추가하고 **Save** 합니다. 기존 `APP_PASSWORD`는 유지하세요. 앱의 **Streamlit Secrets에 영구 설정하기** 안내도 참고할 수 있습니다.

아래는 **Streamlit 앱의 Secrets 입력란에만** 넣는 형식 예시입니다. 필요한 항목만 본인 키로 바꾸며, GitHub 파일에 붙여 넣지 않습니다.

```toml
DART_CRTFC_KEY = "본인 DART 키"
DATA_GO_KR_SERVICE_KEY = "본인 공공데이터 키"
KRX_AUTH_KEY = "본인 KRX 키"
CUSTOMS_API_KEY = "본인 관세청 키"
```

**세션 API 키 모두 지우기**는 세션에 입력한 공공 API 키를 제거합니다. Secrets에 저장한 키는 그대로 사용되므로 완전히 제거하려면 본인 앱의 Settings → Secrets에서도 해당 항목을 삭제하세요. 로그아웃해도 Secrets에 저장한 값은 삭제되지 않습니다.

## 인증정보 보안과 실습 종료

- **`.streamlit.example.toml`은 항목명 확인용 예시 파일입니다. 실제 비밀번호·API 키를 입력하지 마세요.** 이 파일은 GitHub에서 추적되며 `.gitignore`의 제외 대상이 아닙니다. README, `app.py` 등 다른 저장소 파일에도 인증정보를 적거나 커밋·푸시하지 않습니다. 이미 추적되는 파일은 `.gitignore`에 추가하는 것만으로 보호되지 않습니다.
- **증권사 App Key·App Secret·계좌번호는 현재 접속 세션에서만 사용합니다.** Streamlit Secrets나 GitHub 파일에 저장하지 않습니다. 공공 API 키의 선택적 Secrets 저장과 구분하세요.
- **계좌 연결 해제·로그아웃은 세션 입력 API 키, 증권사 연결 정보, 잔고와 접속 중 실습 기록을 지웁니다.** 필요한 실습 기록은 먼저 백업하세요. 공공 API를 다시 쓰려면 세션에 재입력하거나 본인 Secrets에 저장된 키를 사용합니다.
- 서버가 키를 처리하므로 각자 관리하는 본인 앱에서 사용하고, 긴 비밀번호와 비공개 접근 설정을 사용하세요. 키·비밀번호·계좌번호가 담긴 화면이나 파일을 게시판·이슈·PR에 올리지 않습니다.
- 인증정보를 실수로 커밋하거나 공개했다면 해당 서비스에서 즉시 키를 폐기·재발급하고, 비밀번호도 변경하세요. 파일에서 값을 지우는 것만으로는 기존 커밋 이력의 노출이 없어지지 않습니다.
